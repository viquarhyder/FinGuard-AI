FinGuard AI — bundled Inter font files

Included weights:
- Regular (400)
- Medium (500)
- SemiBold (600)
- Bold (700)

These are intended for the FinGuard AI web UI. Inter is an open-source typeface
distributed under the SIL Open Font License 1.1.

Place these files in:
static/assets/fonts/

Example CSS:
@font-face {
    font-family: 'Inter';
    src: url('../assets/fonts/Inter-Regular.otf') format('opentype');
    font-weight: 400;
}
